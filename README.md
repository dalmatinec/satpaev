# Satpaev Store Bot

Telegram бот-магазин: звёзды, NFT подарки, юзернеймы, обмен, разработка и сервера.
Админка полностью на кнопках, любые тексты, кнопки, их порядок и картинки меняются прямо в боте,
постинг в канал от вашего аккаунта с премиум эмодзи, ежедневный бэкап базы на сервер и в личку.

## Установка за 2 команды

На чистом сервере (Ubuntu/Debian):

```bash
git clone --filter=blob:none --sparse https://github.com/dalmatinec/satpaev.git && cd satpaev
git sparse-checkout set --no-cone '/*' '!/site/'
sudo ./setup.sh
```

Папка с сайтом на сервер бота не скачивается: сайт ставится отдельно, см. [site/README.md](site/README.md).

Скрипт сам поставит Docker, спросит токен бота, ваш id, канал и API ID/HASH,
сгенерирует пароль базы и запустит всё. Потом откройте бота: /start для меню клиента,
/admin для админки, /edit включает режим редактирования (команды видны только админам).

## Что внутри

| Сервис | Что делает | Память |
|---|---|---|
| bot | aiogram 3, весь бот и админка | до 256 МБ |
| poster | Telethon, публикует посты в канал от вашего аккаунта | до 128 МБ |
| db | PostgreSQL 15, настроен под маленький сервер | до 256 МБ |
| redis | состояния диалогов, переживают перезапуск | до 64 МБ |

Наружу не открыт ни один порт: бот сам ходит в Telegram, база и Redis доступны лишь внутри Docker.

## Оформление прямо в боте

Быстрее всего через **/edit**: включается режим редактирования, и под каждым экраном бота
у вас появляются кнопки «✏️ Текст» и «🔘 Кнопки». Меняете, нажимаете «👁 Посмотреть экран» и сразу видите результат.
Клиенты этих кнопок не видят. То же самое есть в админке → 🧩 Ещё:
- **✏️ Тексты**: любой текст, который видит клиент. Пишете новый прямо в Telegram, жирный, ссылки и премиум эмодзи сохраняются. Можно вернуть стандартный.
- **🔘 Кнопки и экраны**: порядок кнопок на главном меню и на экранах разделов (стрелки, отдельная строка, раскладка текстом), переименование, премиум иконка и цвет любой кнопки, скрытие кнопок главного меню.
- **🖼 Картинки**: картинка для приветствия и разделов. Показывается по file_id, а сам файл хранится в базе на сервере и попадает в бэкап. После переноса на новый бот картинки перезальются сами.

## Постинг от аккаунта (премиум эмодзи)

1. Получите `api_id` и `api_hash` на https://my.telegram.org, впишите в `.env` (`TG_API_ID`, `TG_API_HASH`).
2. Аккаунт должен быть админом канала, `CHANNEL_ID` указан в `.env`.
3. Войдите один раз:

```bash
docker compose run --rm poster python -m poster login
docker compose restart poster
```

Как защищён аккаунт:
- постер делает только одно: публикует посты из очереди в ваш канал, больше никуда;
- не получает апдейты и не читает чаты;
- пауза между постами 20 секунд (`POSTER_MIN_INTERVAL`), лимиты Telegram (FloodWait) соблюдаются;
- если отправка прервалась, пост не повторяется сам, чтобы не было дублей: в админке он помечен «❔»;
- при сбоях постер переподключается сам, бот от этого не зависит;
- файл сессии лежит только на сервере (`data/poster`, права 600) и в бэкапы не попадает.

Статус постера виден в «⚙️ Админка → 📢 Канал».

## Бэкапы и восстановление

Каждый день в 04:00 (меняется в админке) бот делает `pg_dump`, кладёт файл в `backups/`
и присылает его вам в личку. Прошлый бэкап удаляется и на сервере, и в чате.

Восстановление, в том числе на новом сервере:

```bash
git clone --filter=blob:none --sparse https://github.com/dalmatinec/satpaev.git && cd satpaev
git sparse-checkout set --no-cone '/*' '!/site/' && sudo ./setup.sh
cp /путь/к/backup_XXXX.dump backups/ && ./restore.sh
```

Ручной бэкап: `./backup.sh`.

## Обновление

```bash
./update.sh
```

Подтягивает код из GitHub и пересобирает контейнеры. Данные не трогаются.
Новые поля в моделях база получает сама при перезапуске (лёгкая автомиграция).

## Полезные команды

```bash
docker compose ps                 # статус
docker compose logs -f bot        # логи бота
docker compose logs -f poster     # логи постера
docker compose restart bot        # перезапуск
```

## Сайт

Лежит в папке `site/` и ставится отдельно от бота, лучше на другой сервер. Инструкция: [site/README.md](site/README.md).

## Структура

```
bot/app/
  texts.py         все тексты и кнопки по умолчанию (меняются в админке)
  handlers/        клиентские разделы (звёзды, подарки, юзеры, обмен, разработка, заказы, связь)
  handlers/admin/  админка по разделам
  services/        заказы, постинг, бэкапы, напоминания, настройки
  db/models.py     таблицы и индексы
poster/poster/     постер канала (Telethon)
site/              сайт (деплоится отдельно)
```
