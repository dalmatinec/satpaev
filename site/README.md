# Сайт

Разворачивается отдельно от бота, можно на другом сервере: так IP сервера с ботом нигде не светится.

## Установка (только папка site, без бота)

```bash
git clone --depth 1 --filter=blob:none --sparse https://github.com/dalmatinec/satpaev.git satpaev-site
cd satpaev-site && git sparse-checkout set site
cd site && sudo ./deploy.sh
```

Скрипт поставит Docker (если нет), спросит домен и запустит сайт на Caddy.
Без домена сайт открывается по IP на 80 порту. Когда появится домен:

1. A-запись домена на IP этого сервера (через Cloudflare с оранжевым облаком IP сервера скрыт).
2. В `.env` указать `SITE_ADDRESS=ваш-домен.kz`.
3. `./deploy.sh`: Caddy сам выпустит SSL и будет его продлевать.
4. В боте: Админка → 🧩 Ещё → ⚙️ Настройки → 🌐 Ссылка сайта.

## Настройка

Всё, что меняется часто, лежит в `public/config.js`: юзернейм бота, ссылка на канал,
юзеры на главном экране, бегущая строка и сетка цен на звёзды (держите как в боте).

## Обновление

```bash
./deploy.sh
```

## Фишки

- звёздное небо на канвасе с параллаксом и падающими звёздами, плавающее сияние;
- стеклянные панели с 3D наклоном и подсветкой за курсором, магнитные кнопки;
- лот Fragment с перебором юзернеймов, таймером аукциона и анимацией цены;
- калькулятор звёзд: кнопка «Купить» открывает бота сразу с выбранным количеством;
- проверка формата юзернейма: «Заказать» открывает бота с заявкой на этот юзер;
- терминал с анимацией деплоя в разделе разработки;
- уважение к настройке «уменьшить движение», адаптив под телефоны.
