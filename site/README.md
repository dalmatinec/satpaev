# Сайт

Разворачивается отдельно от бота, можно на другом сервере: так IP сервера с ботом нигде не светится.

## Установка (только папка site, без бота)

```bash
git clone --depth 1 --filter=blob:none --sparse https://github.com/dalmatinec/satpaev.git satpaev-site
cd satpaev-site && git sparse-checkout set site
cd site && sudo ./deploy.sh
```

Если на сервере уже работает nginx (занимает 80 и 443), сайт подключится к нему, а SSL выпустит certbot.
Если nginx нет, сайт поднимется в Docker на Caddy с автоматическим SSL.

## Бесплатный домен DuckDNS и HTTPS

1. Зайдите на https://www.duckdns.org (вход через Google или GitHub).
2. Придумайте поддомен, например `satbox`, нажмите **add domain**.
3. В поле **current ip** впишите IP сервера и нажмите **update ip**.
4. На сервере: `./deploy.sh domain`, введите `satbox.duckdns.org`.

Сертификат выпустится и будет продлеваться сам, сайт откроется по `https://satbox.duckdns.org` без порта.
Этот же адрес подходит для Telegram Mini App.

5. В боте: /admin → 🧩 Ещё → ⚙️ Настройки → 🌐 Ссылка сайта.

## Что берётся из бота

Сайт сам подтягивает из бота (обновляется в течение минуты, без перезапуска):

- курсы обмена и минимальные суммы: /admin → 💱 Курсы;
- цены звёзд и минимум: /admin → ⭐ Звёзды;
- все тексты сайта: /admin → ✏️ Тексты → 🌐 Сайт;
- название бренда и минимальный заказ: /admin → 🧩 Ещё → ⚙️ Настройки;
- проверку юзернейма в реальном времени (статус на Fragment, цена, таймер аукциона).

Бот должен работать на этом же сервере (по умолчанию). Если бот на другом сервере, впишите в `.env`
`API_UPSTREAM=http://IP_БОТА:8090`, а на сервере бота в `docker-compose.yml` поменяйте
`127.0.0.1:8090:8090` на `8090:8090` и откройте порт только для сайта: `ufw allow from IP_САЙТА to any port 8090`.

## Защита

- API только читает данные: ни заказов, ни админки через сайт нет, всё управление только в Telegram;
- API слушает только 127.0.0.1, наружу открыт через nginx с лимитом 2 запроса в секунду с IP;
- в самом боте второй лимит, проверка формата юзернейма, кэш, запросы больше 1 КБ отбрасываются;
- строгий Content-Security-Policy: чужие скрипты на странице не выполнятся, данные вставляются только как текст;
- открыть сайт во фрейме можно только из Telegram (для Mini App).

## Настройка

- **Бот, менеджер, канал** (запасные значения, если бот недоступен): `./deploy.sh config`.
  Сохраняются в `public/config.local.js`, в git не попадают.

## Обновление

```bash
git -C .. pull && ./deploy.sh
```
